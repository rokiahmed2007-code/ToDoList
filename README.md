# ToDoList

A simple To-Do List application built using C# to practise programming concepts and task management functionality.

## 📌 About the Project

ToDoList is a personal project designed to help users organize and manage their tasks. It is part of my journey to improve my C# programming skills and gain practical experience through building projects.

## ✨ Features

- Manage tasks in a to-do list.
- Mark tasks as completed.
- Keep the project organized and easy to understand.

## 🛠️ Technologies Used

- C#
- .NET / Visual Studio

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Visual Studio.
3. Build and run the application.

## 🎯 Purpose

This project was created for learning and practice, with a focus on improving my programming skills and applying what I learn in practical projects.
